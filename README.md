# Todo App

## Features:

- Add task
- Delete task
- Edit task
- Mark complete
- Filter (All / Active / Completed)
- Persist to localStorage

## Concepts:

- Controlled inputs
- List rendering
- State updates
- useEffect
- Derived state

### Interview questions it prepares you for:

- Why shouldn't you mutate state?

- Why do list items need keys?

- When should state be stored vs derived?
